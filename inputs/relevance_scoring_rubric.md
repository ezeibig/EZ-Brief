**Purpose:** Score and structure content for expertise building and thought leadership credibility

### Dimension 2: Functional Relevance (0-3 points)

| Score | Criteria |
|-------|----------|
| **3** | Core domain: Customer Strategy, Customer Analytics, Marketing Transformation, AI in Marketing/CX, Marketing ROI |
| **2** | Adjacent: CMO strategy, Commercial Analytics, Digital Marketing, CRM, Personalization, Agentic AI |

---

### Dimension 3: Executive Applicability (0-2 points)

| Score | Criteria |
|-------|----------|
| **2** | Enterprise-scale implications: Strategic decisions, org design, transformation programs, board-level concerns |
| **1** | Managerial relevance: Team-level applications, tactical insights with strategic implications |
| **0** | Individual contributor or entry-level focus |

---

### Dimension 4: Evidence Quality (0-3 points)

| Score | Criteria |
|-------|----------|
| **3** | Strong evidence: Named research, quantified data, cited sources, documented case studies |
| **2** | Moderate evidence: Expert analysis with some data, practitioner examples, logical frameworks |
| **1** | Weak evidence: Informed opinion, anecdotal, directional but unsubstantiated |
| **0** | No evidence: Pure speculation, vendor hype, unsupported claims |

---

### Dimension 5: Source Credibility (0-2 points)

| Score | Criteria |
|-------|----------|
| **2** | Tier 1: McKinsey, BCG, Bain, HBR, MIT Tech Review, peer-reviewed research, major exec search firms |
| **1** | Tier 2: Industry pubs (FiercePharma, Retail Dive), respected analysts (Stratechery, ChiefMartec), practitioner experts |
| **0** | Tier 3: Unknown blogs, promotional content, unvetted sources |

---

### Dimension 6: Recency (0-2 points)

| Score | Criteria |
|-------|----------|
| **2** | Last 7 days |
| **1** | 8-30 days |
| **0** | Over 30 days |

---

### Dimension 7: Shareability Value (0-3 points)

| Score | Criteria |
|-------|----------|
| **3** | High: Quotable stats, named trends, frameworks you can reference by name |
| **2** | Moderate: Useful context, supports a point, adds depth to perspective |
| **1** | Low: Background knowledge only, wouldn't cite directly |
| **0** | Not shareable: Too niche, too generic, or not credible enough to cite |

## SCORING BANDS

| Total Score | Label | Action |
|-------------|-------|--------|
| **14-17** | **Critical** | Deep read, extract claims with citations, add to talking points library |
| **10-13** | **High** | Read and summarize, note key data points |
| **6-9** | **Medium** | Skim for signals, note if pattern emerges |
| **3-5** | **Low** | Skip unless directly asked about topic |
| **0-2** | **Exclude** | Do not process |

---

## SIGNAL TYPE TAXONOMY

| Value | Definition |
|-------|------------|
| **Leading** | Early indicator of emerging trend; ahead of mainstream adoption |
| **Confirming** | Validates or reinforces an existing trend; adds evidence to known pattern |
| **Lagging** | Documents something already widespread; historical reference value |
| **Contrarian** | Challenges prevailing narrative; potential pivot signal |
| **Structural** | Indicates lasting change to industry/function (org design, business model, capability shift) |

---

## TIME HORIZON TAXONOMY

| Value | Definition |
|-------|------------|
| **Immediate (0-6 mo)** | Actionable now; affects current decisions |
| **Mid (6-24 mo)** | Strategic planning relevance; prepare for this |
| **Long (2-5 yr)** | Directional; shapes vision and positioning |
| **Evergreen** | Timeless principle; always applicable |

## PRIORITIZATION RULES

**PREFER:**
- Evidence-backed claims (data, research citations, named sources)
- Structural changes (org design, operating model, capability shifts)
- Quantified trends with sources

**DE-PRIORITIZE:**
- Personal opinion without data
- Vendor hype / promotional content
- "Thought leadership" without evidence

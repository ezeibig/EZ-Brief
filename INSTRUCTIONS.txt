# EZ-Brief Research & Grounding System
# Startup Instructions
# =====================================================

## PURPOSE

This system builds substantive, credible expertise in target domains
(CPG, Pharma, Hospitality, Retail, Luxury, Telecom) for thought leadership.
It is NOT for job hunting—it's for learning and sharing insights credibly.

## PROJECT STRUCTURE

EZ-Brief/
├── inputs/
│   ├── relevance_scoring_rubric.md   # 17-point scoring methodology
│   ├── rss_feeds.md                   # Master list of sources
│   ├── profile_summary.md             # Your profile context
│   └── weekly_prompt.md               # Workflow instructions (edit this to modify process)
├── grounding/
│   ├── YYYY-MM-DD_scored_articles.md  # Weekly scored output (archived)
│   └── latest.md                      # Current week (fixed URL for Manus)
├── logs/
│   └── YYYY-MM-DD_run_log.md          # Processing logs
└── INSTRUCTIONS.txt                    # This file

## SCORING THRESHOLD

- Score ≥14: CRITICAL - Deep read, extract claims with citations
- Score 10-13: HIGH - Read and summarize, note key data points
- Score 6-9: MEDIUM - Skim for signals (not included in output)
- Score <6: Excluded

## OUTPUT FORMAT REFERENCE

Each scored article follows this structure:

### [Article Title]
**Source:** [Publication] | **Date:** YYYY-MM-DD | **Score:** X/17

**Breakdown:**
Industry [X] | Function [X] | Exec [X] | Evidence [X] | Source [X] | Recency [X] | Shareability [X]

**Signal Type:** Leading | Confirming | Lagging | Contrarian | Structural
**Time Horizon:** Immediate (0-6 mo) | Mid (6-24 mo) | Long (2-5 yr) | Evergreen
**Impacted Roles / Functions:** [1-3 from controlled list]

**Quotable Claims:**
- "Exact quote" — Source

**Key Data Points:**
- Statistic — Source

**Human Synthesis (Draft):**
1-2 sentence framing for conversation


## CONTROLLED VOCABULARIES

Signal Types:
- Leading: Early indicator of emerging trend
- Confirming: Validates existing trend
- Lagging: Documents something already widespread
- Contrarian: Challenges prevailing narrative
- Structural: Indicates lasting change

Impacted Roles (select 1-3):
- CMO
- Customer Strategy
- Customer Experience (CX)
- Data & Analytics
- Marketing Operations
- Commercial/Revenue
- Digital Transformation
- AI/ML Leadership
- Brand
- Insights & Research
- Agency/Partner Management


## PRIORITIZATION RULES

PREFER:
- Evidence-backed claims (data, research citations)
- Structural changes (org design, operating model)
- Quantified trends with sources

DE-PRIORITIZE:
- Personal opinion without data
- Vendor hype / promotional content
- "Thought leadership" without evidence


## AUTOMATOR APP SETUP

To create the one-click EZ-Brief launcher:

1. Open Automator (Applications → Automator)
2. Choose "Application" as document type
3. Search for "Run AppleScript" and drag it to workflow
4. Paste this script:

   ```applescript
   tell application "Terminal"
       activate
       do script "cd '/Users/eugeniazeibig/Desktop/AI Resolution/EZ-Brief' && claude 'Run the weekly EZ-Brief process per inputs/weekly_prompt.md'"
   end tell
   ```

5. File → Save as "EZ-Brief" to Desktop (or Applications)
6. Optional: Drag to Dock for quick access

To change the app icon:
- Find an icon you like (.icns file or image)
- Right-click the app → Get Info
- Drag image onto the icon in the top-left of the info window
